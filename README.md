CrewAI Travel Planner Agent

An AI-powered travel planner built using CrewAI and OpenAI GPT-4o-mini to recommend three places to visit in a selected city.

Features:
Creates a Travel Planner Agent.
Assigns tasks using CrewAI.
Generates three travel recommendations with short descriptions.
Loads API credentials from .env.

Installation:
python -m pip install crewai python-dotenv

Create a .env file: OPENAI_API_KEY=your_actual_api_key

Run : python travel_planner.py

Concepts Learned : CrewAI Agents, Tasks, and Crews.

LLM configuration:
Environment variables using python-dotenv.
Executing tasks with crew.kickoff().
